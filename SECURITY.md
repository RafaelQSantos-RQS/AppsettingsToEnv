# Security Policy

## Supported versions

Only the latest release is supported with security fixes. Use the most recent `v*.*.*` tag.

## Reporting a vulnerability

Do **not** open a public issue for security problems.

Instead, email **rafaelqsantos33@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce it
- The affected version

You'll get an acknowledgment within 7 days and an update on the fix. Please do not disclose the issue publicly until it's resolved.
